# CS336 学习笔记

个人学习记录，跟随 Stanford [CS336: Language Modeling from Scratch](https://cs336.stanford.edu/)（Spring 2025 视频版，[YouTube 播放列表](https://www.youtube.com/playlist?list=PLoROMvodv4rOY23Y0BoGoBGgQ1zmU_MT_)）。

## 学习方式

每周看一讲视频，然后通过和 AI 对话来巩固理解：
1. 看视频时记录自己认为重要的点
2. 看完后带着不明白的问题去讨论
3. 讨论后把收获整理成笔记，存进 [`notes/`](./notes)
